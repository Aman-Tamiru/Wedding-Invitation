## Open locally
1. Extract this folder.
2. Open the folder containing `package.json` in Cursor.
3. Copy `.env.example` to `.env.local` and fill values locally from your Appwrite project. Never share or commit `.env.local`.
4. Run `npm ci`.
5. Run `npm run dev`.
