## Administration
- Owner access
- Staff accounts and roles
- Guest management
- Scanner
- Seating
- Photos and wishes
- Settings

## Technical rules
- Preserve existing working functionality.
- Appwrite remains the primary backend unless the code audit proves otherwise.
- Never expose server credentials to the browser.
- English and Amharic throughout the public and admin experience.
- Preserve Gregorian dates for storage and calculations.
- Display the agreed Ethiopian calendar date in Amharic.
- Protect existing database records and Git history.
